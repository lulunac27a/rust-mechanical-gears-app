# Gear Calculator Web App with WASM

This is a gear calculator web app with WASM/Rust and HTML/JavaScript.

### Getting Started

1. Clone the repository.
2. Change directory: `cd gear_calculator`
3. Build WASM library: `wasm-pack build --release`
4. Open index.html on your browser and enter input values or click on the
   canvas.

The program should be working.
